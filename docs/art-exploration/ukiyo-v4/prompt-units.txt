A concept sheet for a Civilization-like strategy game in exactly the same ukiyo-e woodblock style as the reference game screens: flat colour inside fine black key-block lines, indigo and Prussian blue, sage and ochre ground, vermilion accents, cream paper, Hokusai waves. The camera looks straight down, as on the reference map. Thin cream gutters separate the panels, and each panel has a small plain black caption on the cream gutter below it.
The sheet shows ALL 28 UNITS as a grid of 28 small square map panels, 7 columns by 4 rows, on plain grassland (ships on sea). Each unit is a flat print token with a thin cream outline and a small blue player flag, drawn SMALL, filling only about half of its square so that it would sit well beside a city. Captions: Settlers, Militia, Phalanx, Legion, Chariot, Catapult, Knights; Musketeers, Cannon, Cavalry, Riflemen, Artillery, Diplomat, Caravan; Armor, Mech. Inf., Fighter, Bomber, Nuclear, Trireme, Sail; Frigate, Ironclad, Cruiser, Battleship, Submarine, Carrier, Transport.
