# Working on OpenCivOne

## Visual changes

Any change that affects how the game or a theme looks must pass the `aesthetic-check` skill (`.claude/skills/aesthetic-check/SKILL.md`) before it is called done, fixed or ready, and before it is committed. That means side-by-side crops against the theme's reference renders, at game size and enlarged, checked in the real game, with a verdict per element in the reply. Drawing things in code is fine; they must look like they belong in the art.
